# Aldo’s Vault

Tienda con backend Node, PostgreSQL y almacenamiento privado en Supabase.

Despliegue: [instrucciones](deploy/render-supabase/README.md).

Build: `npm --prefix deploy/render-supabase install --omit=dev`

Inicio: `node deploy/render-supabase/server.mjs`

Configura las variables únicamente en Render. Nunca subas archivos .env ni datos de clientes.
